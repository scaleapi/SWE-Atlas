Several fields are auto-populated here: ihl, len and chksum display as None because they are computed at build time; ttl defaults to 64; proto is auto-set to icmp based on the payload type; dst defaults to 127.0.0.1. The src field is auto-resolved from the routing table by SourceIPField—in this container Scapy finds no usable route (it warns "No route found (no default route?)"), so src falls back to 0.0.0.0; on a typical host with a configured loopback it would resolve to 127.0.0.1 for this destination.

At the network layer, nothing can actually be emitted in this environment: sr() first opens an L3 raw socket (conf.L3socket), and this container denies raw-socket creation (PermissionError, errno 1) and has no default route. The send therefore fails before emission and no ICMP echo replies are received here—zero answers. What a successful sr() session prints is defined in scapy/sendrecv.py, which I verified in the source:

```
$ grep -n "Begin emission" scapy/sendrecv.py; grep -n "Finished sending" scapy/sendrecv.py; grep -n "Received .*packets, got" scapy/sendrecv.py
239:                print("Begin emission:")
250:                print("Finished sending %i packets." % i)
218:                "\nReceived %i packets, got %i answers, "
```

The sending thread prints "Begin emission:" and "Finished sending %i packets.", and the results summary is "\nReceived %i packets, got %i answers, remaining %i packets" (sendrecv.py, around lines 214-222). Note that even on a privileged host where the raw socket opens, an ICMP echo to 127.0.0.1 typically ends with got 0 answers: the kernel handles loopback internally without routing the reply through the network layer where Scapy's listener sits, so no reply is captured.

IP class in scapy/layers/inet.py lines 521-537 defines defaults (verbatim from the source):

```
class IP(Packet, IPTools):
    __slots__ = ["_defrag_pos"]
    name = "IP"
    fields_desc = [BitField("version", 4, 4),
                   BitField("ihl", None, 4),
                   XByteField("tos", 0),
                   ShortField("len", None),
                   ShortField("id", 1),
                   FlagsField("flags", 0, 3, ["MF", "DF", "evil"]),
                   BitField("frag", 0, 13),
                   ByteField("ttl", 64),
                   ByteEnumField("proto", 0, IP_PROTOS),
                   XShortField("chksum", None),
                   # IPField("src", "127.0.0.1"),
                   Emph(SourceIPField("src", "dst")),
                   Emph(DestIPField("dst", "127.0.0.1")),
                   PacketListField("options", [], IPOption, length_from=lambda p:p.ihl * 4 - 20)]  # noqa: E501
```

The Emph() wrappers just mark src/dst for emphasized display; the fields themselves are SourceIPField and DestIPField. post_build() at lines 539-551 computes ihl/len/chksum when they are None. SourceIPField is implemented in scapy/fields.py lines 854-889: when src is not explicitly set, its __findaddr() helper looks up the packet's dst in Scapy's routing table via conf.route.route(dst) and uses the source address of the matching route—which is why src resolved to 0.0.0.0 in this route-less container.
