I built a fresh local binary using

```
PATH=$PATH:/usr/local/go/bin go build -o trufflehog-local .
```

to ensure the logs come from a clean, up-to-date build with no stale artifacts. Then I executed it with high-verbosity logging and detector-timing enabled

```
./trufflehog-local --log-level=5 --print-avg-detector-time filesystem ./sample_scan
```

so that every subsystem activation is visible and detector initialization can be confirmed through timing output. All observations below come strictly from what the running executable printed, no source inspection. The log lines are quoted verbatim from one run; the worker counts scale with the machine's core count, so they will differ on other hosts.
